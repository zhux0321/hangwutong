# 航务通

电脑端货代业务管理应用，当前版本 **v1.4.1（开发演示）**。

## 使用

每次打开须阅读并确认开发中使用提醒。工作台提供订单清单、行内流程状态、待办、截止提醒和船期刷新入口。

“新建待办 → 粘贴 / 导入 PDF、截图，自动新建订单”支持文字、截图及 PDF 订舱单。核对识别字段、销售和时区，处理自检提示并勾选已核对后，一次保存订单及关联待办。SO 使用订舱号，放行条独立保存和提醒。OCR 可能误读，须对照原单；可查看原文件及候选值。PDF / 图片在电脑浏览器内处理，不上传。

v1.4.1 修复港口和船名 / 航次跨行漏填，并在 PDF 关键字段缺失时自动图片补识别；两种结果不同则列出候选要求核对，不自动覆盖。

在“系统设置 → 数据存储”中选择或新建电脑本地文件夹并授权后，订单、待办、备注和已保存设置会写入本地文件，保留上一份备份。GitHub Pages 只提供程序页面，不代为保存业务数据。

配置有效船期数据服务地址后，程序打开期间每小时刷新一次。当前地址为空，真实维运网数据服务需要后续接入。

导入单据保留原文当地时间与时区；CST / PST 等不明确的缩写会提示核实。含原单具体时刻的船期不会被只返回日期的接口覆盖。

## 发布

本目录为 GitHub Pages 静态发布根目录。将全部文件提交到独立仓库，Pages 来源选择 `main` 分支、`/(root)`。`.nojekyll` 用于按静态文件发布，无需构建或安装依赖。

旧站 `bf-js3ec7` 使用独立仓库，本项目不修改或覆盖它。

识别组件复用 [PDF.js](https://github.com/mozilla/pdf.js) 和 [Tesseract.js](https://github.com/naptha/tesseract.js)，自带中英文模型及字体；开源许可见 [vendor/LICENSES.txt](vendor/LICENSES.txt)。为兼容直接打开本地 HTML，须保留完整 vendor 目录。

## 从本地演示迁移数据

新网址和本地 HTML 的浏览器缓存不共用。请先在本地演示的“数据存储”中保存到电脑文件夹，再在新网址选择同一个数据文件夹读取。首次访问新网址仍需要浏览器授权。

## 开发中提醒

本应用可能存在功能不完善、保存失败、数据错误或丢失等情况。请勿作为唯一业务记录；重要数据请另行备份。船期和提醒需在办理业务前核实。
