# 航务通

电脑端货代业务管理应用，当前版本 **v1.3.0（开发演示）**。

## 使用

每次打开须阅读并确认开发中使用提醒。工作台提供订单清单、行内流程状态、待办、截止提醒和船期刷新入口。

在“系统设置 → 数据存储”中选择或新建电脑本地文件夹并授权后，订单、待办、备注和已保存设置会写入本地文件，保留上一份备份。GitHub Pages 只提供程序页面，不代为保存业务数据。

配置有效船期数据服务地址后，程序打开期间每小时刷新一次。当前地址为空，真实维运网数据服务需要后续接入。

## 发布

本目录为 GitHub Pages 静态发布根目录。将全部文件提交到独立仓库，Pages 来源选择 `main` 分支、`/(root)`。`.nojekyll` 用于按静态文件发布，无需构建或安装依赖。

旧站 `bf-js3ec7` 使用独立仓库，本项目不修改或覆盖它。

## 从本地演示迁移数据

新网址和本地 HTML 的浏览器缓存不共用。请先在本地演示的“数据存储”中保存到电脑文件夹，再在新网址选择同一个数据文件夹读取。首次访问新网址仍需要浏览器授权。

## 开发中提醒

本应用可能存在功能不完善、保存失败、数据错误或丢失等情况。请勿作为唯一业务记录；重要数据请另行备份。船期和提醒需在办理业务前核实。
